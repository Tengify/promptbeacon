A few useful details.

Does it change the model for me?

No. PromptBeacon shows your selection. Change the model or reasoning effort in Codex or Claude Code as usual.

Does it color every chat in the sidebar?

The indicator follows the focused session window. It doesn’t modify the host app or add colors to its sidebar.

What if effort is unavailable?

You’ll see “Effort unavailable” with no filled bars. Model color can still work. The exact exposed controls depend on the app and version.

Can I change the colors?

Yes. Add or edit model matching rules in settings, then pick colors you can distinguish. Labels provide a text equivalent for every color signal.
